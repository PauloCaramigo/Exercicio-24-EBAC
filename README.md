# Sobre o projeto
Este projeto tem como objetivo o estudo e aprendizado sobre o PWA e fazer o site desenvolvido funcionar sem a necessidade de uma conexão com a internet.
#

# Como rodar o projeto
Este projeto foi idealizado para rodar com a extensão Live Server do Visual Studio, devido ao PWA precisar de uma conexão e não funcionar apenas acessando o arquivo index.html localmente. <br />

Ao realizar a instalação da extensão "Live Server", basta abrir o arquivo index.html com a extensão e somente com isso já é possível realizar verificar o PWA implementado no site.
